# School AI — локальный помощник по документам школы

Система отвечает на вопросы по внутренним документам школы (положения, приказы,
инструкции, материалы IB и т.п.) и **всегда показывает, из какого пункта какого
документа взят ответ**. Всё работает на Mac Studio в школе: документы и вопросы
никуда в интернет не отправляются.

```
Вы задаёте вопрос
   │
   ▼
Поиск по документам ── находит подходящие пункты (по смыслу, по словам,
   │                    по названию раздела, по номеру пункта)
   ▼
Локальная модель Qwen3 ── формулирует ответ ТОЛЬКО по найденным пунктам
   │
   ▼
Проверка программой ── номера пунктов берутся из базы, а не из ответа модели;
   │                    пропущенные пункты перечня добавляются автоматически
   ▼
Ответ + ссылки на пункты документов
```

## Из чего состоит

| Компонент | Что делает | Где работает |
|---|---|---|
| **Ollama** + `qwen3:14b` | языковая модель: формулирует ответы | Mac Studio, только `127.0.0.1` |
| **Ollama** + `qwen3-embedding:4b` | превращает текст в «смысловые векторы» для поиска | Mac Studio |
| **PostgreSQL 17 + pgvector** | хранит документы, их структуру и векторы | Mac Studio, только `127.0.0.1` |
| **school-ai** (этот репозиторий) | разбор документов, поиск, проверка ответов, API | Mac Studio, `/opt/school-ai`, `127.0.0.1:8000` |
| **Open WebUI** | чат для пользователей: учётные записи, история, выбор «модели» | Mac Studio, порт `8080` |

```
Пользователь ──► Open WebUI ──┬─► «📘 Документы школы» ──► school-ai (поиск + проверка) ──► Ollama
                              └─► qwen3:14b (обычный чат без документов) ──────────────► Ollama
```

**Где что главное:**

* **код** — главная копия в этом репозитории, на сервер его отправляет `deploy/sync.sh`;
* **документы** — главная копия **на сервере** (`/opt/school-ai/data`);
  `deploy/backup.sh` копирует их к вам в `local/data`.

## Быстрый старт

Все команды — на **вашем компьютере**, в папке репозитория.

**Открыть чат (Open WebUI):**

```bash
deploy/tunnel.sh
```

Откроется `http://localhost:8080`. В списке моделей выберите **📘 Документы
школы** — ответы будут только по документам, со ссылками на пункты.
Пока окно терминала открыто, интерфейс работает. После открытия доступа в
локальную сеть (см. `docs/03-maintenance.md`) сотрудники заходят напрямую:
`http://192.168.2.101:8080`.

**Добавить документы** — положите файлы в `local/data/documents/<папка>/` и:

```bash
deploy/push-data.sh
```

**Обновить код на сервере** после изменений в репозитории:

```bash
deploy/sync.sh
```

**Сделать резервную копию** (документы, база, пользователи и чаты Open WebUI):

```bash
deploy/backup.sh
```

Скрипты попросят пароль администратора Mac Studio (для `sudo`).

## Основные команды на сервере

| Команда | Что делает |
|---|---|
| `school-ai check` | проверить, что Ollama, модели и БД работают |
| `school-ai docs` | список документов в базе |
| `school-ai ask "вопрос"` | задать вопрос (`--debug` — показать, что нашёл поиск) |
| `school-ai parse файл` | показать, как система «видит» структуру файла (без записи в БД) |
| `school-ai index` | проиндексировать новые/изменённые документы |
| `school-ai eval` | прогнать контрольные вопросы |

Команда `school-ai` сама запускается от служебного пользователя `service`
и при первом вызове спросит пароль администратора.

## Важные принципы

1. **Модель не источник истины.** Номер пункта, название документа и текст
   источника всегда берутся из базы. Ссылки модели на несуществующие
   фрагменты отбрасываются.
2. **Только локально.** Ollama, PostgreSQL и API School AI слушают только
   `127.0.0.1`. Наружу (в сеть школы) открывается только Open WebUI — с входом
   по логину и паролю.
3. **Пароли и ключи — только в `/opt/school-ai/config/*.env`** (права `600`),
   не в git и не в чатах.
4. **Сгенерированные тексты проверяет человек.** Особенно — будущие Progress Reports.
